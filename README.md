# Responsive Contact Form Section

A modern contact form section built using HTML and CSS.  
This project features a clean two-column layout that displays contact information alongside a functional message form.

## Technologies Used
- HTML5
- CSS3
- Flexbox

## Features
- Responsive contact form layout
- Two-column design (contact info + message form)
- Modern UI styling
- Input fields for name, email, and message
- Contact information section with icons
- Clean and minimal design

## Purpose of the Project
This project was created as part of my front-end development practice to improve my skills in layout design, form styling, and building real-world website sections.
